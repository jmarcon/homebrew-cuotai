# Homebrew tap for Cuotai

Install [Cuotai](https://github.com/jmarcon/cuotai), the monitor for AI usage limits, quotas and costs.

```sh
brew tap jmarcon/cuotai
brew install --cask cuotai   # desktop app
brew install cuotai          # terminal (CLI/TUI)
```

The `Casks/` and `Formula/` files are generated and updated by the Cuotai release pipeline from each verified GitHub Release. Do not edit them by hand; report problems at https://github.com/jmarcon/cuotai/issues.
